# APKM import

Open APK and drag-and-drop accept standalone `.apk` files and `.apkm` split bundles. A bundle stays intact as the library source; extracting `base.apk` loses required architecture splits.

The importer stages flat APK entries in a unique temporary directory (maximum 64 APK files and 2 GB uncompressed APK data). It rejects duplicate names and nested/traversing paths before extraction, checks all package identities and version codes with APK Analyzer, and chooses native splits for the first supported device architecture while retaining non-native configuration splits. Android validates signatures and installs the selected files together using `adb install-multiple -r`. Existing app data is retained; no uninstall, downgrade override or signature bypass is used. Temporary APKs are removed when the import service is disposed. The original bundle's checksum, path and version are retained for the library.

The user's Tap Titans 2 8.3.0 bundle contains base.apk plus ARMv7, ARM64 and x86-64 splits. Its declared package is com.gamehivecorp.taptitans2, version 803000 and minimum API 32. The default Android 14 emulator is API 34 and has an x86-64 split available in this bundle. Metadata declarations alone do not prove gameplay compatibility.

Validation: clean Debug and Release builds, 128 automated tests passed. The complete Tap Titans 2 bundle installed through the app: Android Package Manager reported base.apk and split_config.x86_64.apk for version 803000. Its process remained running, and the decoded viewport screenshot matched Android's screenshot, showing the game's first-run terms dialog beneath the Android fullscreen tip. Game terms were left for the user; gameplay was not exercised. The persistent device retains the installation. Evidence: artifacts/tap-titans-830-test.json and associated screenshots/activity output. The test did not overwrite saved library selection; opening the original bundle normally adds it to the desktop library.
